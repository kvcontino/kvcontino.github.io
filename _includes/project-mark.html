{% comment %} Project marks. Called as {% raw %}{% include project-mark.html mark=p.mark %}{% endraw %} -- Jekyll 3's include tag takes `param=value`, and `param: value` is a hard build error, not a silently empty parameter. Valid keys: pyramid, catchment, diverge, series, catalog, toponym, choropleth, shelf, deck. An unknown key renders nothing. THE RULE: a mark is a miniature of the FORM the project's own figures take, not a logo for its subject. That is why two projects can share one — the two town-population maps ARE the same object with different geography, and `choropleth` says so. Give a project its own mark when its form is its own, not because it feels important. Drawn on a 40x40 viewBox, rendered at about 40px, so one unit is roughly one pixel and stroke widths mean what they say. This is the site's THIRD mark scale and each has its own grid: the nav icons are 24x24 at ~17px, and the home page's figure marks are 120x76 at 160px. Do not scale a drawing between them — the four marks here that also appear on the home page were redrawn at this size, because the age pyramid's sixteen bars and the relocation grid both turn to mud under about 80px. Same form, different drawing. Every stroke is currentColor or var(--ink-faint), so the row's link colour drives the whole mark and hover needs no separate rule. Structure (axes, baselines) is ink-faint; the thing being shown is currentColor. The faint baseline at y=35.5 is the same device the home page marks use. {% endcomment %} {% case include.mark %} {% when "pyramid" %} {% comment %}Age pyramid. Six bands a side, not the home mark's eight: below 4px of pitch the gaps close and it reads as a solid arrowhead.{% endcomment %} {% when "catchment" %} {% comment %}Street grid, one address, and the area reachable from it. The catchment turns in right angles along the grid rather than being a circle: the screen measures what the network reaches, never a Euclidean radius, and a round blob would state the opposite. No baseline rule on this one. The grid already supplies four horizontals and verticals; a fifth line along the bottom reads as one more street rather than as the ground the other marks sit on. The drawing also runs to the edges of the box where the home page's version has room to breathe — at 40px the same proportions closed into an undifferentiated blob.{% endcomment %} {% when "diverge" %} {% comment %}Two paths from a common origin, one dashed: what was projected against what happened. The dash is the counterfactual, which is the whole argument of a post-mortem.{% endcomment %} {% when "series" %} {% comment %}One series over time with a run-up and a fall — the shape an enrollment monitor exists to show.{% endcomment %} {% when "catalog" %} {% comment %}Index entries: a row per record, each with its own tick. The general-purpose mark for a catalogue, register or inventory.{% endcomment %} {% when "toponym" %} {% comment %}Three located dots, each with its name set beside it, inside a territory. Two earlier attempts failed for opposite reasons. A single dot with a leader and a label read as a fishing rod -- one instance of a thing is a picture of that thing, where three in a scatter is a picture of the PRACTICE, which is what a study of place names is about. But the three dots ALONE then read as a bulleted list, because a left-aligned column of dot-plus-rule is the universal icon for one. The faint boundary is what makes them places rather than bullets, and it is the only element here doing that work -- do not drop it as clutter.{% endcomment %} {% when "choropleth" %} {% comment %}Parcels of an irregular territory, shaded by value. The general-purpose mark for any town-, county- or tract-level map — reused deliberately, because two such maps of different places are the same object. Six parcels in two ragged rows. Three cells were drawn first and were worse, not simpler: with all three meeting at one interior point and shaded light on top, dark below, the eye assembled an isometric CUBE and the map vanished. The defence against that is division lines that stay roughly parallel to the box edges and more cells than a solid has faces. Three shades — unfilled, faint, full — because that is a choropleth's actual structure, a legend of classes rather than an outline with decoration.{% endcomment %} {% when "shelf" %} {% comment %}Spines on a shelf. Four, not six: below about 6 units of width the stroke eats the interior and they read as a picket fence.{% endcomment %} {% when "deck" %} {% comment %}A screen on a stand: a talk rather than a document. The general-purpose mark for slides and presentations.{% endcomment %} {% endcase %}
